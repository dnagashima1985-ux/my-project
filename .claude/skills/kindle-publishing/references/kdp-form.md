# KDP「Kindle 本の詳細」入力シート（雛形）

画面の項目順。`{{ }}` を実値に置き換えて `kdp-form.md` として納品する。
毎回ゼロから作らず、この順序を守ると入稿画面で迷わない。

> **本のタイトル欄は出版後に変更できない。** 貼ったあと必ず確認する。

## 言語
```
日本語
```

## 本のタイトル
```
{{title}}
```
**タイトルのフリガナ**（カタカナ）
```
{{title_kana}}
```
**ローマ字**（括弧・ピリオド・コンマ・アポストロフィは使用不可。半角スペースのみ）
```
{{title_romaji}}
```
**サブタイトル**
```
{{subtitle}}
```
**サブタイトルのフリガナ** / **ローマ字**
```
{{subtitle_kana}}
{{subtitle_romaji}}
```

## レーベル ← 発行元はここ
KDPには「出版社」欄がなく、レーベル欄が出版社表記に相当する。
```
フットボールパラダイム
フットボールパラダイム        （フリガナ）
Football Paradigm            （ローマ字）
```

## シリーズ
**空欄。** 既刊がシリーズ登録されていないため、1冊だけ登録しても効果がない。
将来まとめるなら既刊にも同じシリーズ名を設定する必要がある。

## 版
**空欄。** 初版では不要。出版後に変更できない欄なので、迷ったら空欄。

## 著者
```
{{author}}
{{author_kana}}      （フリガナ）
{{author_romaji}}    （ローマ字・半角英字）
```

## 著者等
**空欄**（共著者・監修者がいる場合のみ）

## 内容紹介（4000文字まで）
`kdp-listing.md` の内容紹介を貼る。エディタ右上の**「ソース」**を押すと
HTMLモードになり、`<b>` `<ul><li>` `<br>` 付きのまま貼れる。

## 出版に関して必要な権利
```
● 私は著作権者であり、出版に関して必要な権利を保有しています。
```

## 主な対象読者
```
露骨な性的表現：● いいえ
対象年齢：空欄（児童書・YA以外は入れないほうが読者層を狭めない）
```
**カテゴリー選択ボタンは、この質問に答えるまで押せない。**

## 主なマーケットプレイス
```
Amazon.co.jp
```

## カテゴリー（最大3つ）
検索窓から選ぶ。3枠目はスポーツ以外に振る（理由は house-style.md）。
```
1. {{category_1}}
2. {{category_2}}
3. {{category_3}}
```

## キーワード（最大7つ・各50文字以内）
タイトル／サブタイトルに含まれる語は入れない。
```
1. {{kw1}}   5. {{kw5}}
2. {{kw2}}   6. {{kw6}}
3. {{kw3}}   7. {{kw7}}
4. {{kw4}}
```

## 本の発売オプション
```
● 本の発売準備ができました
```
提出から販売開始まで最大72時間。この間は編集できない。
