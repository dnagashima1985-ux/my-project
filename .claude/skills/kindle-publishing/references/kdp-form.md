# KDP「Kindle 本の詳細」入力シート（雛形）

2026年9月の画面に合わせた項目順。`{{ }}` を実値に置き換えて、本のフォルダに
`kdp-form.md` として置く。**頼まれなくても毎回出す。** 原稿・表紙と同じ納品物。

> **出版後に変更できない欄がある。**本のタイトル、サブタイトル、版。
> 貼ったあと、必ず声に出して読んで確認する。
>
> **サブタイトルを入れると、タイトルとの間にコロン( : )が自動で入る。**
> 商品ページでは `タイトル: サブタイトル` と表示される。長さはこの形で見る。

**このまとめを必ず先頭に置く。**フリガナとローマ字を本文中に散らすと、
転記のときに必ずどれかが抜ける。抜けると入稿画面で止まる。

## 5. シリーズ（オプション）
**空欄。** 既刊をシリーズ登録していないので、1冊だけ入れても効果がない。
まとめるなら既刊にも同じシリーズ名を入れる必要がある。

## 6. 版（オプション）
**空欄。** 初版では不要。出版後に変更できない。

## 8. 著者等（オプション・最大9人）
**空欄。** 共著者・監修者・翻訳者がいる場合のみ、役割を選んで追加する。

## 9. 内容紹介（4000文字まで）
`kdp-listing.md` の内容紹介を貼る。エディタ右上の**「ソース」**を押すと
HTMLモードになり、`<b>` `<ul><li>` `<br>` 付きのまま貼れる。

## 13. カテゴリー（最大3つ）
「カテゴリーを選択」から選ぶ。3枠目はスポーツ以外に振る（理由は house-style.md）。
```
1. {{category_1}}
2. {{category_2}}
3. {{category_3}}
```

## 14. キーワード（最大7つ・各50文字以内）
タイトル／サブタイトルに含まれる語は入れない（すでに検索対象で、枠の無駄）。
```
1. {{kw1}}   5. {{kw5}}
2. {{kw2}}   6. {{kw6}}
3. {{kw3}}   7. {{kw7}}
4. {{kw4}}
```

## 15. 本の発売オプション
```
● 本の発売準備ができました
```
提出から販売開始まで最大72時間。この間は編集できない。
予約注文にする場合、配信日は最大18か月先まで設定でき、延長は2回・合計6か月まで。
