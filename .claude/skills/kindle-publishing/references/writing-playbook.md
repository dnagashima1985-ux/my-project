# 書き方の手引き

この仕事で失敗するとしたら、ほぼ間違いなく**枠組みの作り方**でつまずく。
だからここが一番長い。

## なぜ資料の目次をなぞってはいけないのか

参考資料が優れているほど、その構成をそのまま使いたくなる。だがそれをやると、
出来上がるのは「資料の解説書」になる。問題は3つある。

1. **読者が買う理由がない。** 原典を読めばいい
2. **著作権が危うい。** 章立てごとの要約は再構成であって、独立した著作ではない
3. **著者の顔が出ない。** シリーズを続けるほど、これは効いてくる

資料は**証拠の供給源**であって、設計図ではない。

## 枠組みの作り方

### 手順

**1. 資料から「事実」だけを抜き出す。** 研究知見、数字、各国や各社の実践。
この段階では資料の章立てを無視して、カードを並べるように箇条書きにする。

**2. 「読者の困りごと」を一つに絞る。** 資料が答えている問いではなく、
**日本の読者が実際に困っていること**を書く。ここで初めて本の主題が決まる。

**3. その困りごとを説明する構造を、自分で組む。** 段階モデル、対の概念、
層、サイクル。手元の事実カードが全部どこかに収まるまで組み替える。

**4. 名前をつける。** 覚えられない枠組みは使われない。

**5. 検算する。** 「この枠組みは資料のどこにも書かれていないか？」
書かれていたら、それは借り物なので作り直す。

### 良い枠組みの条件

- **数を伴う**（5つ、7つ）。3つは薄く、9つは覚えられない
- **順序に意味がある**。並べ替えても成立するなら、それは単なるリスト
- **一段深い主張がある**。「AだからBが起きる」という機序を含む
- **反直感な含意が出る**。当たり前の結論しか出ないなら弱い

例（『才能を見落とさない七つの関門』の場合）：
才能が組織に届くまでの7段階を「関門」と呼び、各関門の通過率が掛け算に
なることを示した。ここから「名人を一人雇うより全関門を底上げしたほうが効く」
という反直感な結論が出る。この掛け算の議論は原典のどこにもない。

### 名前のついた道具を作る

読者が明日使えるものを、章ごとに1つ。名前をつけると本の外でも生き残る。

例：「三語の宣言」「割れ表」「月齢の鏡」「戻り道リスト」「引き継ぎテスト」

道具には**書式と運用ルール**を必ず添える。「表を作りましょう」では動かない。
列名と、1行だけの運用の掟（「割れ幅2以上は必ずもう一度観る」）まで書く。

## 章の型

全章を同じ形にする。読者が探し物をしやすく、書く側も迷わない。

```
# 第N章 ○○——一行で言い切る副題

## 漏れ（問題）の正体
何が、どう失われているのか。読者の実感から入る

## 証拠
研究と実践。誰の研究かを名指しで引く

## 日本の事情
制度・慣行・季節。ここが本の価値の半分

## 塞ぎ方
具体策を番号つきで。すぐ実行できる粒度まで下ろす

## 道具：○○
名前のついた書式。列名と運用の掟

## 測り方
この章の状態を数字で見る指標を3〜6個

## 現場ワーク N：○○
所要時間つき。30〜90分で終わる実作業

---

**第N章の要点**
- 箇条書きで6〜9行
```

## 文体——中学生が読める日本語で

**基準は「中学生が辞書なしで読めるか」。** これは読者を下に見る話ではない。
読者は指導者であり、練習の合間や電車で読む。難しく書かれた本は、賢く見えるだけで
読み進められない。やさしく書かれた本のほうが、**速く読めて、実際に使われる。**

### 具体的なルール

**一文は40字前後まで。** 2行を超えたら切る。切れないなら、一文に二つのことを
入れている。

- ✗ 選考基準の明文化がなされていない組織においては、評価者間の判断のばらつきが
  生じやすく、結果として選考の妥当性が担保されない
- ○ 基準が書かれていないと、評価はばらつく。ばらついた選考は、当たらない

**漢語より和語。** 熟語を並べると意味が固まって見えるが、読む速度は落ちる。

| 使わない | 使う |
|---|---|
| 実施する | やる／おこなう |
| 必要である | いる |
| 可能である | できる |
| 有している | ある／持っている |
| 起因する | 〜のせいで／〜から起きる |
| 顕著である | はっきりしている |
| 阻害要因 | じゃまをしているもの |
| 選考基準策定 | 選ぶときの基準を決める |

**「〜において」「〜に関して」「〜という点で」を使わない。** ほぼ全部、
「〜で」「〜は」に置き換わる。置き換えられないなら、文をつくり直す。

**抽象名詞を動詞に戻す。** 「記録の実施」→「記録する」。
「〜の重要性が指摘されている」→「〜が大事だ」。

**受け身を減らす。** 誰がやるのかが消えると、読者は自分の話だと思わなくなる。

- ✗ 選手は評価される
- ○ あなたが選手を評価する

**一段落は3〜4文。** 長い段落は、画面では壁になる。

**カタカナの専門語は、初出で一言そえる。** 現場語（スカウティング、ポテンシャル）
は無理に訳さなくていい。ただし初めて出したときだけ「＝将来どこまで伸びるか」の
ように短く補う。

**数字は具体的に。** 「多くの」より「60〜80%」。ただし出典のない数字は書かない。

**太字は一段落に1回まで。** 増やすと、どれも効かなくなる。

**「〜と言えるでしょう」「〜ではないだろうか」を使わない。** 言い切るか、書かない。
自信のない主張は、根拠を足すか消す。

### 書いたあとの自己点検

各章を書き終えたら、次を機械的に確認する。

1. 2行を超える文はないか（あれば切る）
2. 上の表の左側の語が残っていないか
3. 段落が5文以上になっていないか
4. その章で初めて出たカタカナ語に、説明がついているか

読み上げてみるのがいちばん速い。息が続かない文は、長すぎる。

## 分量

| 部位 | 目安 |
|---|---|
| はじめに | 1,500〜2,000字 |
| 序章（枠組みの提示） | 2,500〜3,000字 |
| 各章 | 3,500〜6,000字 |
| 終章 | 2,000字 |
| 付録（チェックリスト・用語集・出典） | 4,000〜5,500字 |
| **合計** | **45,000〜55,000字** |

序章で枠組みを完全に説明しきること。ここが弱いと、以降の章がバラバラの
読み物になる。

## 巻末に必ず置くもの

1. **付録**：本文の道具をまとめたチェックリスト、道具一覧、用語集
2. **出典**：主要典拠と、参照した研究・実践を名前つきで列挙
3. **原典との関係**：原典に存在しない要素（枠組み、道具、実装手順）を
   具体的に列挙した1段落
4. **免責**：著者の提案であって原典の団体の見解ではない旨
5. **奥付**：書名・著者・発行元・©・書式の利用許諾

3と4は省略しない。読者への誠実さであり、権利上の防御でもある。

## 倫理

対象が子ども・選手・個人になる本では、次を本文の中で明示する。

- 分類する道具は人を傷つけうる、という自覚
- 記録は本人の目に触れても構わない言葉で書く
- 個人情報の扱い（誰が見られるか・どこに置くか・いつ消すか・どう説明するか）

これは体裁ではない。この種の本は放っておくと「人を資源として扱う」議論に
滑り落ちるので、歯止めを本文に埋め込んでおく。
