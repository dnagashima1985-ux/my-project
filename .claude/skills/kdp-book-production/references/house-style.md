# シリーズの体裁（フットボールパラダイム）

既刊15冊以上から抽出した共通ルール。新刊は書棚に並べたときに
シリーズとして揃って見える必要があるので、ここは創作しない。

## 命名

タイトルは**キーワード先行の実務型**。詩的な一行を主題にしない。

既刊の例：『年齢別育成プロセス』『5-3-2システムにおけるディフェンス』
『ZONE14』『Not the game, but the players』
『勝利を導く監督とそのキーファクター: トータルフットボールの生みの親』

検索される語（ポジション名、システム名、年代、概念名）をタイトルに入れる。
詩的な一行は**表紙の煽りコピー**に回すと機能する。読者はキーワードで探し、
煽りで手を止めるので、役割を分けたほうが両方生きる。

サブタイトルは「〜の設計図」「〜の第一歩」のように、
何の本かを名詞で言い切る。

## 著者と発行元

- 著者：フットボールパラダイム（実名にする場合は本人に確認）
- 発行元：フットボールパラダイム
- KDPには「出版社」欄がなく、**レーベル欄**が出版社表記に相当する
- 表紙ではタイトル上部に小さく「発行元　フットボールパラダイム」
- 巻末に奥付を置き、書名・著者・発行元・©・書式の利用許諾を書く

## 表紙の文法

```
┌─────────────────┐
│                             │
│      図（ドット／図解）      │  上半分：抽象図。写真は使わない
│                             │
├─────────────────┤  ← オレンジの罫（ドット図のときだけ）
│ 発行元　フットボールパラダイム │  小さく
│ タイトル前半                 │  138px
│ タ イ ト ル 後 半             │  214px 極太
│ サブタイトル                 │  52px
│                             │
│ 煽りコピー          ╭─────╮ │  104px 赤またはオレンジ
│ 補足2行             │ バッジ │ │  ギザギザの円
└─────────────────┴─────┘
```

- 背景はフラットな1色。生成り `#F5F2EC` か紺 `#123B6D`
- アクセントはオレンジ `#F08A24`、煽りは赤 `#C0392B`（白地）／
  オレンジ（紺地）
- バッジは必ず「サッカー／指導者に／ひらめきを」の3行
- バッジ色は表紙ごとに変えてよい（青 `#1B5FA8`、赤、紺）
- 写真もイラストも使わない。図形だけで作る（外部素材の権利問題を避けられ、
  シリーズとして揃う）

**サムネイル基準**：Amazonの一覧では横180px程度で表示される。
その大きさでタイトルが読めるかを毎回確認する。`build_cover.py` が
`-thumb.png` を書き出すのはこのため。

## カテゴリーの取り方

KDPは最大3つ。**全部をサッカー枠に入れない。**
既刊がサッカー枠に集中しているので、3枠目をスポーツ以外
（人材・人事・教育・マネジメント）に振ると、自著どうしでランキングを
取り合わずに済む。

## キーワードの取り方

7つまで、各50文字以内。**タイトルとサブタイトルに含まれる語は入れない**
（すでに検索対象なので枠の無駄）。実際に読者が打ちそうな語の並びにする。

例：`サッカー 指導者` `才能発掘 タレント発掘` `相対年齢効果 早生まれ`
