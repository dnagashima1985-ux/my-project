# 第3章 頭の疲れ——新しい約束事は、週に一つ

## 何が起きているか

体は元気なのに、判断だけが遅い。そういう日がある。

パスの選択が一つ遅れる。前を向けば通る場面で、後ろに戻す。守備では、行くべきか待つべきかで足が止まる。走行距離は落ちていない。むしろ多いこともある。**動いてはいるが、決めていない。**

こうなるチームには、共通点がある。**約束事が多い。**

先週から新しいビルドアップの形を入れた。今週は守備のスライドを変えた。ついでにセットプレーの配置も直した。どれも良い変更だ。一つずつなら。

三つ同時に入れると、選手の頭の中では、ボールが来るたびに三つの確認が走る。これが頭の疲れだ。そして頭の疲れは、**走力と技術の両方を落とす。**

## 証拠

スミスとクーツらが2016年に発表した実験が、この関係をはっきり示している。

選手を二つの状態に分けた。片方は30分の集中課題（ストループ課題という、色と文字が食い違う刺激に反応し続ける作業）をやってから、もう片方は30分雑誌を読んでからテストを受ける。体は一切動かしていない。**違いは頭を使ったかどうかだけである。**

結果はこうだ。集中課題のあとでは、間欠的な走力テスト（ヨーヨーIR1）の成績が落ちた。別の研究群では、パスとシュートの正確さも落ちた。本人たちの「きつさ」の感じ方は上がっているのに、やる気は変わっていない。

**30分の頭の作業が、走力と技術を同時に削った。**ボールにも触れず、走ってもいないのにだ。

シアトル・サウンダーズのデイビッド・テニーは、この点を実務の言葉にしている。ゲームモデルを通じたトレーニングは、**毎回のセッションで身体・感情・認知の要求を釣り合わせる**ことだ、と。プレッシングの練習は、有酸素能力と、疲れた状態での判断と、感情の耐性を同時に鍛えている。

裏を返せば、**同時に消耗させてもいる。**フラーデもセイルーロも「切り離せない」と言った。切り離せないなら、疲れも切り離せない。

## もう一段深く：約束事には「在庫」がある

ここで、本書の中心にある考え方を出しておきたい。**チームの約束事は、三つの状態のどれかにある。**

1. **新品**——今週入れたばかり。使うたびに考える必要がある
2. **定着中**——だいたいできる。だが疲れると忘れる
3. **自動**——考えなくても出る。疲れていても出る

頭の疲れを作るのは、1と2だけだ。3はほとんど消耗させない。むしろ楽にする。

**そして頭の容量は、試合中はほぼ一定である。**新品と定着中の合計が容量を超えると、超えた分だけ判断が遅れる。ここが本書の主張の中心だ。推論を含むが、現場で起きることをよく説明できる。

例を出す。ある高校が、8月から11月までの12週で戦い方を変えたいとする。入れたい変更は12個ある。やり方は二つ。

**やり方A：最初の3週で12個を一気に入れる。**選手は覚えきれない。使うたびに考える。11月の時点で「自動」になっているのは、たぶん2つか3つ。残りは疲れると消える。

**やり方B：週に1個ずつ、12週かけて入れる。**1個入れたら、次の週は前の1個を使い続けながら、新しい1個を足す。3週目には、最初の1個は「定着中」に移っている。5週目には「自動」になり始める。

12週後、Bのチームには**自動が7〜8個、定着中が3個、新品が1個**という在庫ができる。同じ12週で、同じ12個を扱っている。違うのは順番だけだ。

Aが失敗する理由は、意志の問題ではない。**新品を3つ以上同時に持てないからである。**

ここから運用の掟が一つ出る。**新しい約束事は、週に一つ。**入れたいものが3つあるなら、順番を決める。決められないなら、それは優先順位が定まっていないという意味だ。

そしてもう一つ。**約束事を減らすことも、練習である。**古くなった約束事を消すと、頭に空きができる。空きができれば、新しいものが入る。

## 日本の事情

日本の現場には、この在庫を溢れさせる事情が三つある。

**一つ目。週の練習回数が少ない現場ほど、1回に詰め込む。**週2回のクラブが、1回の練習で三つのテーマを扱う。回数が少ないぶん濃くしたい気持ちは分かる。だが頭の容量は、練習の回数では増えない。

**二つ目。ミーティングが長い。**試合前日に30分の映像を見せる。相手の分析、自チームの修正、セットプレー。これは前章までの分類でいえば、**練習ではなく負荷である。**スミスらの実験は、まさに「30分の頭の作業」の影響を測ったものだった。

**三つ目。テスト期間。**中学・高校では、年に何度か、選手全員が数日間ずっと頭を使い続ける週が来る。この週に新しい戦術を入れるのは、条件としてはいちばん悪い。

## どう組むか

1. **新しい約束事は、週に一つまで。**二つ入れたい週は、どちらかを翌週に回す
2. **入れる日は週の初め。**試合から48時間以上あけた、体が軽い日に置く
3. **試合前日は、新品ゼロ。**確認だけにする。新しいことは一つも足さない
4. **映像は10分まで。**それ以上必要なら、日を分ける
5. **テスト週は、戦術を止める。**維持だけにして、新品はゼロ
6. **四半期に一度、約束事を捨てる日を作る。**使っていないものを消す

## 道具：約束事の在庫表

紙一枚を三つに割り、いま持っている約束事を並べる。

| 新品（今週） | 定着中 | 自動 |
|---|---|---|
| 逆サイドへの展開の合図 | 前からの守備の追い方 | ゴールキックの立ち位置 |
|  | 中盤の背後を消す動き | 攻撃時の幅の取り方 |
|  |  | コーナーの守り方 |

**運用の掟：新品の欄は、常に1行以内。**2行になったら、片方を消して翌週に送る。

移す基準も決めておく。**疲れた終盤の練習でも出せたら「定着中」から「自動」へ。**ミーティングで説明しなくても選手が言えたら「新品」から「定着中」へ。

この表は、指導者が自分のためだけに持っていてもいい。だが選手に見せると、もっと効く。「いまチームが練習しているのはこれ」がはっきりするからだ。

## 測り方

- **練習の最後に「今日の狙いを一言で」と聞く。**同じ答えが半分以上から返れば、伝わっている
- **試合後のミスを二つに分ける。**「技術のミス」と「判断のミス」。判断のミスが増えている週は、頭の疲れを疑う
- **新品の約束事が実際に出た回数を数える。**1試合で3回以下なら、まだ新品のままだ

## コラム　指示の言葉も、頭の負荷である

約束事の数を数えるとき、たいてい見落とされるものがある。**練習中の声かけだ。**

グラウンドで指導者が出す指示は、選手にとっては全部「その場で処理する情報」である。「もっと開け」「早く」「見て」「今のは戻す場面」。一つひとつは短くても、10分間に30回飛べば、30回の判断の割り込みが起きている。

**声かけは、練習中に約束事を足しているのと同じことだ。**しかも紙には残らないので、誰も数えていない。

試してほしいことがある。**練習の1メニューだけ、一言も言わずに見る。**終わってから、まとめて三つだけ伝える。

多くの指導者がこれをやると、二つのことに気づく。一つは、**言わなくても選手が自分で直す場面が思ったより多いこと。**もう一つは、**自分が言おうとしていたことの半分は、いま言う必要がなかったこと**である。

声を減らすのは、放任ではない。**いつ言うかを設計している**ということだ。判断が固まる前に声が飛ぶと、選手は自分で決める経験を失う。決める経験がなければ、試合で決められるようにはならない。

目安を一つ置く。**一つのメニューにつき、割り込みは3回まで。**残りは、メニューの切れ目にまとめて言う。

## 現場ワーク：在庫を棚おろしする（60分）

1. いまチームにある約束事を、思いつくかぎり紙に書き出す（15分）
2. 一つずつ、新品・定着中・自動のどれかに振り分ける（15分）
3. 「自動」に入れたものを、次の練習の終盤に一つ試す。出なければ「定着中」に戻す（10分）
4. 半年以上使っていないものに線を引いて消す（10分）
5. 残った「新品」が2つ以上あるなら、順番をつけて1つに絞る（10分）

初めてやると、たいてい書き出しの時点で驚く。**自分が思っていたより、選手に要求している数は多い。**

---

**第3章の要点**

- 頭の疲れは、走力と技術の両方を落とす。30分の集中課題だけで起きる（スミス、クーツら2016）
- ミーティングは練習ではなく負荷である。映像は10分まで
- 約束事は「新品・定着中・自動」の三つの状態を持つ。消耗させるのは前の二つ
- 新品を3つ同時には持てない。同じ12個でも、順番が違えば定着数が変わる
- だから新しい約束事は週に一つ。試合前日は新品ゼロ
- 古い約束事を消すことも練習である。空きを作らないと新しいものは入らない
- テスト週は戦術を止めて、維持だけにする
